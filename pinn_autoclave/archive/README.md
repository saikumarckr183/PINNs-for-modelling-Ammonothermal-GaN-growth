# Archive

Earlier versions and drafts of the scripts in the main folders, kept to document how the models developed.
Their contents are unchanged from when they were written, so their data paths still point to the old project layout,
and they were written for an older ScimBa version than the one in `requirements.txt`.

`one_gan_part_early.py` and `two_gan_parts_dd_early.py` are the first GaN models (soft interfaces; the two-piece
script uses an older geometry with both pieces at r = 5 mm). They reached an RMSE of several kelvin against CrysMAS and were replaced by the scripts in
`4_autoclave_2d_heat/`.
